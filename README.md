# Memory Dungeon Game: design

Design work for an optional game tab in Memory, the director's personal ADHD memory app: a party-based JRPG dungeon crawler with automatic combat, where real-life quests pay unlocks and dungeons pay gear. That pitch is `docs/concept-spec.md`, and it stands.

What's being built right now is the **core set**: a vertical slice of that game, designed by the director as four documents in `docs/core-set/`. It has the rules, combat, classes, gear, formations and enemies, and none of the progression, quests or rewards. The full game grows out of it later.

Start with `CLAUDE.md` (how to work, and where things stand), then `docs/core-set/README.md` (the slice), `docs/method.md` (how each design step is done) and `DECISIONS.md` (what's been decided).
