# Step 5g tuning trail

One entry a round. Each round: a feel read (`reads/round-N.md`), the changes made on it, and what `npx tsx src/rogue-feel.ts` (48 runs, fixed seeds, every class drafted) says afterwards. The knobs are frozen at 5f's values throughout; win rates are context.

0. **Baseline, 5f's build as committed.** The tool: 376 fights from 48 runs (one run won). Regular fights 49 / 55 / 65 ticks by act, elites 53 / 88 / 68, bosses 69 / 79 / 133 (the act-3 bosses 18 to 415 ticks). Statuses in the fights where they were applied: Burn 28% of the party's damage, Shock 22%, Bleed 17%; peaks: Burn 32 (cap 40), Shock 23 (cap 30), Chill 6 (cap 12), Sunder 10.5 (cap 20). One application against the caps, at base stats: Firebolt 29 Burn, Fire arrow 28, Frost lance 16 Chill (cap 12), Blizzard 8, Thunder chord 21 Shock, Chain lightning 17 on each of four, Frenzy 16 Might (cap 15), Anthem 12, Enfeeble 16 Sunder, Rending arrow 16. Damage by source: the Pyromancer 16 / 25 / 60 (basic / abilities / statuses), the Stormcaller 24 / 21 / 55, the Hexer 40 / 0 / 60, the Frostweaver 50 / 50 / 0, the Cleric and Bard 100 / 0 / 0 by construction, the Vampire 48 / 39 / 13. Third-slot casts a fight: Pyre 0.48 (first t41), Fireball 0.53 (t35), Unmake 0.20 (t45), Tremor 0.40 (t54), Sanctuary 0.50 (t45), Aspis 0.70 (t39). The read is `reads/round-0.md`.

5. **Round 5: the director's answers built.
