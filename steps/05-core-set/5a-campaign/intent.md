# Step 5a intent: the campaign

From the director's message in the session of Oct 25, 2026, after playing the core set in the interface. Not an interview: the items are their words, lightly cleaned, and the tags are the session's reading of how firmly each was held. There was no read-back, since they asked for the work to run overnight; correct anything here and the design follows.

## What they found playing the core set

- "Having everything available all the time is really cool for you to simulate things and test… but to me, it's just like there's too many options, too much content all at the same time, and it's just like impossible to really tell what works, what doesn't work, and learn the game in any way."
- "The game is dramatically too easy. I'm pretty sure it's impossible to lose, or nearly. It doesn't matter what party you use, and I haven't put any gear on anyone."
- "Balancing is all off. It's impossible to stack burn. You can never get more than one or two stacks. I think poison does one damage most of the time."

## The ask

- [firm] Make the core set "a beatable experience": you start with your starter classes, your starter formation, and the first dungeon. "As you beat content, you unlock more dungeons, more gear, more formations, more classes", so you can "actually appreciate what you've unlocked and try and progress through the game."
- [firm] "You only unlock one dungeon at a time, or one new challenge, or one new whatever. I want the player to have to beat things and feel like, oh, I can't progress unless I beat things. I don't get a reward for rebeating something I've already beaten."
- [firm] Feedback: "If there's a way to unlock something, it needs to be clear. There needs to be a celebration moment when I unlock it where I see what it is. It needs to be understandable in the menu how I can find the thing I've unlocked. So don't go crazy on that last one." New interfaces get matching menus, in the style there is.
- [lean] More content to beat than the documents hold, by two routes:
  - remixes: "remix, recolor, or even just fight in different orders… create your own encounters even if they're not part of the full design, two of the same boss";
  - replays with conditions, framed as needs rather than bans: "not you can't use the Pyromancer. You must try to beat it with a Bard and Cleric party, pick your third", "you must try to beat it with this formation", "everyone wearing heavy armor", "maybe the enemies have a buff"; "you can't start it if your party doesn't have that condition".
- [lean] Use the simulation to balance it so it's "fun for me to try to beat as a playtester", and use the structure to make that tractable: challenges "constrain the sample set dramatically", and "everything in the unlock route can be deterministic… you know the tools available to the player for each dungeon that you're designing."
- [lean] Balance isn't the whole of it: "is there really enough vertical progression for it to not just be like you're using the same party over and over? My hope is that the formations are a way to do that."
- [idea] Unlocking abilities for units over time: "probably going nuts right now. We have too much already."

## How to work

- [firm] "This is really an exploratory attempt at trying out a game structure, and I'm ok if I don't end up pushing it to main. So don't be afraid to make decisions, create new content if you need/want to and if you're able to simulate it to make sure it works and is interesting." They'll play it from this branch.
- [lean] Simulate as much as needed, use helpers; it runs overnight.
- Art: the packs they uploaded are there if needed, not required.

How many nodes, which rewards where, the needs and remixes, the numbers, and the rules changes the balance needs.
