# The campaign: report

You asked for the core set as a game to beat: start with the starters and the first run, unlock everything one node at a time, with remixes and trials that set needs on the party, balanced by simulation. It's built and on this branch. This report leads with what needs you; `design.md` beside it has the route in full and `tuning.md` the trail.

**To play it:** `npm install`, then `npm run ui` and open the address it prints (on a phone on the same Wi-Fi, the Network address). GitHub Pages only publishes `main`, so the published app is still the old version. The game opens on the journey. Your old free-play party is kept: Settings → MODE → FREE PLAY brings back the everything-available sandbox.
